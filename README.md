## 🧑‍💻 Vibe coding & AI coding

1. [Cursor](https://cursor.com) ⭐ **Best pick**: Editing a real codebase with an AI pair programmer. *Free plan + paid.*
2. [Claude Code](https://claude.com/product/claude-code): Agentic coding from your terminal. *Paid.*
3. [Lovable](https://lovable.dev): Prompt-to-full-stack web app, no setup. *Free plan + paid.*
4. [Bolt.new](https://bolt.new): Spinning up and deploying web apps in the browser. *Free plan + paid.*
5. [Replit](https://replit.com): Building and hosting apps with Replit Agent. *Free plan + paid.*
6. [v0](https://v0.app): Generating React/Next.js UI from prompts. *Free plan + paid.*
7. [GitHub Copilot](https://github.com/features/copilot): Inline completions in VS Code & JetBrains. *Free plan + paid.*
8. [Windsurf](https://devin.ai/desktop): AI-native IDE alternative to Cursor (now renamed Devin Desktop by Cognition). *Free plan + paid.*
9. [Faylee](https://faylee.app): One-link bug reports (video, console, network, steps) that Claude Code, Codex or Cursor can read over MCP and fix; free for up to 3 members. *Free plan + paid.*
10. [Backenly](https://backenly.com): Backend (Postgres, auth, storage, realtime) your coding agent builds over MCP, with self-healing and human approval for risky changes; free plan. *Free plan + paid.*
11. [MAO](https://trymao.dev): Desktop canvas to run Claude Code, Codex, Grok and other agents side by side; 7-day free trial, then $20 one-time. *Paid.*
12. [AC Bridge](https://www.ac-bridge.com): Turns your smart lights and plugs into status lights for Claude Code and Codex; 7-day free trial, then £2.99/month. *Paid.*

9. [telemetry.dev](https://telemetry.dev): OpenTelemetry-based tracing, cost and latency for LLM apps and agents; free 30k ingestion units a month. *Free plan + paid.*

## Recent releases

- **2026-11-04**: ChatGPT Images 2.6 with GIFs and reusable reference images: OpenAI released Images 2.6 in ChatGPT and Codex on all plans, on desktop, mobile and web. OpenAI says it generates images 50% faster and keeps characters, products and brand details more consistent across edits. You can now turn a prompt or an image into an animated GIF (adjust speed, edit single frames) and save reference images of yourself, pets or characters to reuse. Developers get two API models, GPT-Image-2.6 Flare (fast, as little as six seconds at low quality) and GPT-Image-2.6 Sunburst (more detail), plus image markup and SVG export. ([source](https://openai.com/index/introducing-images-2-6/))
- **2026-11-04**: Tencent Hy4 language model with vision and computer use: Tencent released the official version of Hy4, its newest large language model. It adds image understanding and computer use (command line and on-screen apps) for the first time, with Tencent reporting gains over the August Hy4 Preview in instruction following, long documents and long agent tasks. It is live in Tencent's WorkBuddy, CodeBuddy, Yuanbao and Tencent Cloud TokenHub, and through OpenRouter. API pricing stays at about US$0.90 per million input tokens and US$2.70 per million output tokens. Tencent says the open weights and system cards come in the coming days; they were not out at launch. ([source](https://www.tencent.com/tencent-launches-hy4-joining-the-ranks-of-the-worlds-leading-open-source-ai-models/))
- **2026-11-04**: Suno: start a song from a MIDI file: You can now drag a .mid or .midi file onto Suno's Create page (or pick MIDI from the + menu) and use it as the starting point for a song. A MIDI file carries exact notes and timing but no sound, so you describe in plain words how closely Suno should follow it: play the notes exactly as written on new instruments, such as a full orchestra or a string quartet, or take a motif and develop it into something new. ([source](https://suno.com/blog/MIDI-in-create))
- **2026-11-04**: FlutterFlow launches an AI-native app builder for iOS and Android: FlutterFlow introduced a new AI-first builder: you describe an app, an AI agent builds the screens, backend and sign-in, and you refine it in conversation, test it on your own phone and publish to the App Store and Google Play. It includes a managed database, authentication and basic analytics, and the agent can work on several tasks at once. FlutterFlow's existing visual builder continues as FlutterFlow Studio; existing subscribers can try the new builder under their current plan, subject to usage limits. ([source](https://www.flutterflow.io/flutterflow-vs-studio))
- **2026-11-02**: Meituan LongCat-2.5 multimodal agent model: Meituan released LongCat-2.5, a natively multimodal model built for long-running agent work: coding across large codebases and whole projects, visual coding from images, design and 3D tasks. Meituan says it has 1.6 trillion total parameters and was trained entirely on Chinese domestic chips. Available now in the LongCat chat (longcat.ai) and through the LongCat API, which Meituan says works with agent harnesses such as Claude Code and Codex; GitHub and Hugging Face releases are planned but not out yet. ([source](https://longcat.ai/blog/longcat-2.5))
- **2026-11-02**: Runway Dev plugins for Claude Code, Codex and Cursor: Runway launched Runway Dev plugins for Claude Code, Codex and Cursor. One install connects your coding agent to your Runway Dev (API) account through the Runway Dev MCP and adds Runway's skills, so the agent can see your projects, models, prices and credit balance, build features such as a product video for every store item with Runway's SDKs, and look up error details when a generation fails. Sign-in happens on first use; no API key is stored in the plugin. ([source](https://runway.com/news/developers/runway-dev-plugins-for-coding-agents))
- **2026-11-02**: Notion Agent APIs generally available: Notion's Agent APIs are out of beta. Developers can start and stream chat sessions with Notion Custom Agents from their own apps, manage agents, and now also chat with and manage the personal agent (Notion AI) with a personal access token, using notion_ai as the agent ID. A new update endpoint changes an agent's name, description, model or status in one request. The old private alpha routes are deprecated. ([source](https://developers.notion.com/page/changelog))
- **2026-11-02**: Wix Studio Two AI-native editor (rolling out): Wix announced Studio Two, a new editor for agencies and professionals that combines its AI agent Aria 2.0, drag-and-drop design on an infinite canvas and standard React code in a browser-based VS Code. Projects can be imported, exported as React projects to keep working in Claude, Codex, Cursor or any IDE, and hosted on Wix or deployed elsewhere; Skills save reusable instructions, and MCP tools let AI agents manage Wix Stores, Bookings and more. Rolling out to Wix Partners first, then gradually to all users; existing Wix Studio sites stay supported. ([source](https://www.wix.com/press-room/home/post/wix-introduces-studio-two-a-truly-open-ai-native-visual-editor-for-professional-web-creation))
- **2026-11-02**: Framer Agent Harness 2: whole workflows in one program: Framer rebuilt the harness behind the Framer Agent so it can do a whole workflow, such as finding every use of an old brand color and replacing it, in one JavaScript program instead of one command per edit. Code runs while the model is still writing it, so changes appear on the canvas sooner, and a failed check stops generation early. Framer says this makes the agent up to 33% cheaper and 20% faster. External agents such as Claude Code, Cursor or ChatGPT Desktop now get the same tools through Framer's MCP. ([source](https://www.framer.com/blog/harness-2/))
- **2026-10-30**: Claude Ultra plan replaces Max 20x: Anthropic renamed its top consumer Claude plans: Max 5x is now simply Max ($100/month, 5x Pro usage) and Max 20x is now Ultra ($200/month, prices unchanged). Ultra gives 10x Pro usage every week, $200 a month in Claude API credits, and no five-hour usage limit for verified accounts; the weekly limit still applies. Existing Max 20x subscribers move to Ultra automatically. ([source](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan))
- **2026-10-29**: Mistral Large 4 (Le Chonk) open weights: Mistral released the weights of its improved Mistral Large 4, a natively multimodal Mixture-of-Experts model with about 1T total and 49B active parameters per token, a 1M-token context, text and image input, and three reasoning modes. Mistral says it leads open-weight models in coding and defensive cybersecurity. Weights (FP8 and NVFP4) are on Hugging Face under the Mistral Ecosystem Open-Weight License, a modified MIT license that requires a separate commercial license for Model-as-a-Service businesses. Also on the Mistral API as mistral-large-4 at $0.70 input and $2.10 output per million tokens, and on OpenRouter. ([source](https://mistral.ai/news/mistral-large-4-oss/))
- **2026-10-29**: Canva Brush, a vision-language model for design edits: Canva's in-house vision-language model that looks at an existing design and makes the edits you ask for, from one line of copy to every slide in a deck, using an agentic loop that writes and runs code and then checks the page. Canva says it is up to 69% faster and 46% cheaper per edit than its previous design agent. Available now in Canva AI for Canva Pro subscribers (pick 'Brush' in the Canva AI dropdown), with wider availability coming. ([source](https://www.canva.com/newsroom/news/canva-brush/))
- **2026-10-29**: Pika H3 Flex open-weights video model: Pika's post-trained version of MiniMax H3 for fast, controllable video: up to 12 image, video and audio references in one generation, synchronized audio exported as up to five separate stems (dialogue, score, SFX, foley, ambience), a 768p draft mode with upscaling to 4K, and editing of characters, camera moves and voices. Pika says it can make a 15-second clip in about 7 seconds of compute. Available now through the Pika API, with open weights and inference code on GitHub and Hugging Face; coming to pika.art on November 2. ([source](https://pika.art/blog/pika-h3-flex))
- **2026-10-29**: ElevenLabs SFX v3 sound effects model: ElevenLabs' third-generation text-to-sound-effects model handles prompts that describe several sounds in one scene more reliably, generates music and vocals more convincingly, and sounds cleaner than SFX v2 in ElevenLabs' testing. Available now in ElevenCreative (Sound Effects tab, Flows, Studio and the Music Editor) and through the ElevenLabs API. ([source](https://elevenlabs.io/blog/sound-effects-v3))
- **2026-10-29**: Factory Droid 1.0 coding agent: Factory released Droid 1.0, a rebuilt version of its model-independent coding agent. Programmatic tool calling is now the default: the model writes a short sandboxed script that runs many tool calls in one request, which Factory says cut cost by 15% on Claude Opus 5.5. Factory also reports a smaller base prompt, faster startup and lower memory use, and claims higher Terminal-Bench 4 scores at lower cost than other harnesses on the same models (its own benchmark runs). Available now as a desktop app for macOS and Windows, a terminal app and the Droid SDK. ([source](https://factory.com/news/frontier-harness))
