## 🧑‍💻 Vibe coding & AI coding

1. [Cursor](https://cursor.com) ⭐ **Best pick**: Editing a real codebase with an AI pair programmer. *Free plan + paid.*
2. [Claude Code](https://claude.com/product/claude-code): Agentic coding from your terminal. *Paid.*

5. [Replit](https://replit.com): Building and hosting apps with Replit Agent. *Free plan + paid.*
6. [v0](https://v0.app): Generating React/Next.js UI from prompts. *Free plan + paid.*
7. [GitHub Copilot](https://github.com/features/copilot): Inline completions in VS Code & JetBrains. *Free plan + paid.*

## Recent releases

- **2026-10-27**: Replit Cloud Agents for company codebases: Replit Cloud Agents let anyone on a team describe a change in plain language and get a tested pull request (GitHub) or merge request (GitLab) on the company's existing codebase. The agent tests the change in the running app in a cloud sandbox and attaches screenshots and video; engineers still review and approve. Shared environments are set up once by an admin, and requests can start from @Replit in Slack. Available now for all Replit Pro and Enterprise customers; skills-from-review-feedback is in early access. ([source](https://replit.com/blog/anyone-can-bring-ideas-to-company-codebase))
- **2026-10-27**: MAI Image 2.7 (Microsoft AI image editing model): Microsoft AI's latest image editing model, launched in preview: restyle or relight whole scenes, change text and symbols inside an image, restore and enhance assets, and make edits that need an understanding of objects, lighting and environments. Microsoft says it improves on MAI Image 2.6 across all 10 use cases and 7 editing actions in Artificial Analysis's image-editing evaluation. ([source](https://microsoft.ai/news/mai-image-2-7-debut/))
- **2026-10-27**: Liquid AI LFM3 open-weight small models: Liquid AI's new generation of Liquid Foundation Models: six open-weight models of about 2B parameters on one shared LFM3-1.7B backbone, covering text, vision, audio, omni and two decision models. Built for on-device use (the text model fits in about 1 GB at 4-bit) with a 256K context window for text, and each can be fine-tuned on a single GPU. Available on Hugging Face, the Liquid Playground and the Liquid AI API, with llama.cpp, MLX and vLLM support. ([source](https://www.liquid.ai/blog/lfm3))
- **2026-10-26**: Higgsfield Playable: make a mobile game from a prompt: Higgsfield Playable turns a text prompt, a gameplay idea or your own assets into a playable 2D or 3D mobile-style game you can test in the browser, with 8 genres (shooter, runner, puzzle and more). Playable Games is on all Higgsfield plans and can also be generated through Claude with Higgsfield MCP; Enterprise customers can export a game as a playable ad (single HTML file) for 9 ad networks including AppLovin, Unity Ads, Meta and TikTok Pangle. ([source](https://higgsfield.ai/blog/higgsfield-playable-ads-and-games))
- **2026-10-26**: GPT-6.1 Terra: OpenAI's new mid-tier GPT-6 model for everyday work: detailed visual reasoning, precise computer use and clearer, more natural writing. OpenAI says standard API prices are 50% lower than GPT-5.6 Terra and GPT-6.1 Sol, and it completes computer-use tasks over 3x faster than GPT-6 Astra and GPT-6.1 Sol; GPT-6.1 Sol and GPT-6 Astra remain the picks for the hardest coding. Available in ChatGPT Work, Codex and the API (gpt-6.1-terra), and on Amazon Bedrock. ([source](https://openai.com/index/introducing-gpt-6-1-terra))
- **2026-10-26**: Runway App Studio: Describe a creative tool in plain language and App Studio builds a no-code app with its own interface that generates images, video and audio using your Runway Brand Kits and Workflows; existing Workflows can become an app in one click. Ships with built-in apps (Character Swap, AutoComp, Product Portfolio, 3D Camera Control, Precise Edit). Building is on all paid plans with no add-on, using existing credits; free users can run built-in and shared apps. ([source](https://runway.com/news/company-news/introducing-runway-app-studio))
- **2026-10-24**: Kimi K3.1 Pro and K3.1 Pro Highspeed: Moonshot AI's new flagship, a post-trained version of Kimi K3 with a 1M-token context window, aimed at coding (including Unity, Unreal and Godot projects), 3D creation, financial research and agent tasks; the Highspeed variant runs 2-3x faster. Live on Kimi.com, the Kimi apps, Kimi Work, Kimi Code and the Kimi API; Moonshot says full open weights follow by 4 November and that cyber-related training data was removed for the open-weight release. ([source](https://www.kimi.com/blog/kimi-k3-1-pro))
- **2026-10-23**: OpenAI Agents API adds Scheduled Automations: Developers can now schedule agent runs in the OpenAI Agents API, either recurring with a cron expression and time zone or once at a set future time, starting a new session or continuing an existing one. Agents given the automations tool can also create, update or remove their own schedules from natural-language requests. ([source](https://community.openai.com/t/introducing-scheduled-automations-to-the-agents-api/1409223))
- **2026-10-23**: Gemini Notebook becomes a Connected App in the Gemini app: Type @Gemini Notebook in a Gemini chat (or just ask) to create, edit or delete notebooks, add or remove sources, save notes and answer questions from your notebooks without leaving the chat. Available now to Google Workspace customers, Workspace Individual and personal Google accounts; on by default except in the EEA. ([source](https://workspaceupdates.googleblog.com/2026/10/take-actions-on-your-notebooks-from-Gemini-Notebook-directly-in-the-Gemini-app.html))
- **2026-10-23**: Replit Monitoring Agent: Replit Agent can now act as an on-call engineer for published apps: with Monitoring alerts and Auto-fix on, it investigates production issues from the app's logs and metrics in the background and attempts and validates fixes, which you review and publish (or let an experimental Auto-republish setting ship). The same update lets Agent create reusable workspace skills and adds chat and asset sharing. ([source](https://docs.replit.com/updates/2026/10/23/changelog))
- **2026-10-22**: Ideogram Vector 1.0: Ideogram's first vector model generates clean, editable SVGs (logos, wordmarks, lettering, illustrations, labels) from a text prompt, or converts an existing image into a scalable vector, with editable colors, shapes and gradients for Illustrator, Figma or code. Live in the Ideogram app, the API (from US$0.10 per image conversion and US$0.13-0.32 per generated SVG) and partner platforms. ([source](https://ideogram.ai/models/vector/))
- **2026-10-22**: OpenAI Decisions API generally available: OpenAI's API for fast bounded-answer decisions (classify, route, pick the next agent action) built on GPT-6 Luna is out of beta. New since beta: native GPT-Live integration for voice apps, prompt caching, native JSON inputs, images in question instructions, up to 400 questions per request and US/EU inference residency. US$0.10 per million input tokens (US$0.01 cached), no output-token charges. ([source](https://openai.com/index/decisions-api/))
- **2026-10-22**: Canva Craft, Canva's first in-house image model: Canva Research's design-focused image model plans the layout, elements and text before rendering, at up to 2K resolution in 30+ aspect ratios, with text in 55 languages and outputs that convert into editable layers (Magic Layers). Available to all Canva users in Dream Lab and to developers through Canva's public API; Canva MCP support and faster variants are coming. ([source](https://www.canva.com/newsroom/news/canva-craft/))
- **2026-10-22**: Google Meet speech translation expands to 63 languages: Gemini-powered real-time speech translation in Google Meet now covers 63 languages on web, Android and iOS, auto-detects who is speaking which language and lets each participant turn translation on for themselves, with matching translated captions. Rolling out now to Rapid Release Workspace domains and from 2 November to Scheduled Release domains, on eligible Workspace and Google AI plans. ([source](https://workspaceupdates.googleblog.com/2026/10/real-time-speech-translation-in-google-Meet-expands-to-63-languages-with-automatic-language-detection.html))
- **2026-10-22**: 1Password for Agents: Lets personal AI agents sign in to sites without ever seeing your password: the agent requests a login, you approve it on your device, and 1Password fills it in directly. Integrations with Meta Muse and Grok Bot rolling out now; Claude Duet, ChatGPT Work/dots and Town coming soon. No extra cost for 1Password Individual and Family accounts on 1Password.com. ([source](https://1password.com/blog/1password-for-ai-agents))
